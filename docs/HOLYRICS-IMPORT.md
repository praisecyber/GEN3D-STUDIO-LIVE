# Read-only Holyrics song import

Enable API Server in Holyrics under File → Settings → API Server. Create a token with read access for authentication, GetSongs and GetLyrics. In GEN3D Projection Studio, expand Import from Holyrics, enter the server address and token, then read the library. The default example is `http://127.0.0.1:8091`; use the actual address/port shown by your installation. HTTPS or a trusted LAN is recommended.

GEN3D obtains a session/nonce from Auth, authenticates with SHA-256 of `nonce:0:token:auth`, then signs each read with `nonce:rid:token:JSON-body`. Request IDs increase sequentially. The raw token is not put in a URL, persisted or logged. Cancel aborts the read. Reads have a two-minute overall deadline, a 15-second request timeout and a 20 MB response limit. Redirects are rejected. Only Auth, GetSongs and GetLyrics are used; the source presentation/library is not modified.

Review the result before Add reviewed songs. Matching local titles are preserved. Basic text slides follow the documented one-based comma-separated order, including repeated choruses. Artist, author, copyright, notes, source key/groups and archived status are retained as song metadata and visible under Song credits & source notes. Archived source songs import as normal library entries with their source status preserved. Use source groups as library filters is selected by default and applies only to newly added songs. You can switch it off during review. Existing local songs and group assignments are preserved. GEN3D supports up to 10 filter groups per song with names up to 40 characters; review warnings identify names beyond those limits, while every original source group stays in the song metadata. Songs and group assignments save together with rollback if storage fails.

Alternatively, choose a UTF-8 JSON file containing the documented GetSongs response (`{"status":"ok","data":[...]}`) or its data array. This is not support for proprietary binary backups. Empty/styled-only slides or invalid ordering exclude the affected song and produce a review warning. Source themes, linked audio/media, cloud accounts, translations and alternate arrangements are not migrated. Credentials are never included in a project/song backup.

Protocol basis: the public API reference under https://github.com/open-mission/holyrics-control-app/tree/main/apps/server/docs/holyrics-api, inspected 2026-10-26. Its Lyrics model documents GetSongs from v2.21 and later additions. Compatibility was tested against local protocol fixtures, including authentication proofs, HTTP failures/cancellation and native preview/apply behavior. A running Holyrics installation has not been tested; no complete/versioned vendor compatibility claim is made.

Validation: `npm test` and `DISPLAY=:99 npm run test:holyrics` from desktop. The latter uses a real local HTTP server and Electron, not a live Holyrics instance.
