GEN3D Studio Live 0.11.0 adds **Online 3D Studio**, an independent client for official Tencent Hunyuan3D-2mini on your own Kaggle GPU session.

- Image-to-3D mesh generation; text-to-3D through an SDXL-Turbo reference image.
- Authenticated GPU connection, cancellation, local GLB library, model preview and GLB export.
- Generated models affect projection only after you select **Use reviewed model on projection**.

Download the Windows x64 EXE (or extract the ZIP), and **GEN3D-Kaggle.ipynb** for Kaggle. In Kaggle enable GPU and Internet, create a private `GEN3D_GPU_TOKEN` Secret of at least 32 characters, and run the notebook. Connect the desktop app using its printed HTTPS URL and your token. Keep the notebook running. See [the setup guide](https://github.com/praisecyber/GEN3D-STUDIO-LIVE/blob/main/docs/HUNYUAN3D-ONLINE.md).

**Development preview:** actual Hunyuan/SDXL inference and free-GPU memory fit on Kaggle have not been validated here. The automated tests use synthetic inference fixtures; no fake model is used in the app. Kaggle controls GPU availability, quotas and session timeouts; this is not always-on hosting. The free-GPU profile produces untextured, unrigged geometry. It does not create singing or facial animation.

The Windows installer remains unsigned; physical Windows/Android acceptance is outstanding. The Android build is unchanged and is not part of this release. Model weights are not included. Tencent's license and the separate SDXL-Turbo license apply; see the included Tencent agreement and setup guide. This is not a full Holyrics/Hunyuan feature-parity claim.

SHA256SUMS.txt lists the hashes of this Windows-runner build's downloads. Earlier manifests under docs describe earlier cloud artifacts.
